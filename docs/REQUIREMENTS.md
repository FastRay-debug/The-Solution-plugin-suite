### Module engines (real DSP per module)
- ✅ The Bunker: sub-harmonic synthesizer (octave-down divider following 50-160 Hz), dynamic low tamer (120 Hz shelf dips only when lows boom, up to -12 dB), 3-layer Split-Core M/S (LR4 bands summing flat, per-band width, movable crossovers); all neutral by default so the original tuning is untouched
- ✅ The Anchor clipper suite: single or 4-band (120 Hz / 1 kHz / 6 kHz LR4), curves Soft / Gold smooth-knee / Tube / Hard / Arctan / Sine Fold + knee, drive to 1585% (+24 dB), ceiling, output, blend; transparent look-ahead limiter mode (1.3% vs 24% distortion); dynamic multiband (eases hot bands, same level: 20% → 4% distortion); 1x-16x oversampling with fixed latency; PAM keeps parallel blend flat (0.01 dB vs 25 dB comb); squash/crest detector shows CLEAN / GLUE / CRUNCH / SQUASHED. Off = original Anchor sound
- ✅ The Aether: particle cloud (granular grains from the last ~3 s; XY pad = texture/density with live particle view; scatter, spread, pitch unison/octave up/down/fifth/shimmer, freeze) + delay (1/16-1 bar tempo-synced or free, feedback, ping-pong, Focus, Soften, Duck against your playing or the Rack Link sidechain, Tape wow/flutter + saturation); both mixes 0 by default = original sound
- ✅ The Mosaic: STFT spectral morph (1024 / 2048 / 4096, 75% overlap; morph 0 reconstructs the input exactly), 4-node XY pad (Air / Warm / Hollow / Radio, right-click a corner to capture what is playing; saved with the session), Morph amount, transient preservation (click fidelity 3.5 → 26 dB); latency (4096) only while on
- ✅ The Void: procedural acoustic modeller - draw the floor plan (drag/add/remove corners, presets Studio / L-Room / Hexa Hall / Corridor / Cathedral), place sound and listener (arrow keys, MIDI/joystick-mappable); image-source reflections to 2nd order + floor/ceiling with real delays, absorption and direction; 8-line FDN tail at the Sabine RT60 (measured 0.39 s vs 0.43 s); Warp = non-Euclidean path bending; Scramble = phase-scrambling diffusion (same level, L/R correlation 0.03); bioluminescent wireframe view with pulsing reflection paths
- ✅ The Land: outdoor acoustics - ground-bounce image source (notch exactly at 343/2Δr: 345 Hz, -22 dB on concrete at 10 m), 7 surfaces (grass, concrete, snow, water, sand, forest floor, gravel), air absorption with distance, wind (the bounce drifts and flutters), terrain (open field, valley slap, canyon walls, urban street flutter); side-view drawing with live notch readout
- ✅ HOA ambisonics output (AmbiX ACN/SN3D, 1st-3rd order) - every module, The Land included
- ✅ The Orbit: triode tube stage with true bypass (grid-conduction asymmetry, bias drift, supply sag, coupling + Miller roll-off; H2 leads at -11.5 dBc) · Regen Throttle clocked loop (tempo-synced or free; throttle = feedback, soft run-away past 1.0; loop clock 2-48 kHz with BBD anti-alias + reconstruction: lower clock = darker, grittier repeats) · Auto-Connect wizard (Ctrl+Alt+O): recognises every track (vocal, bass, drums, guitar/keys, pads, FX) and routes it to a spatial zone, optional dialogue ducking for the music beds
- ✅ The Bridge: hosts third-party VST3 (AU on macOS) - chain of 4 with own editor windows, bypass, dry/wet mix (dry delayed to match: >60 dB null), reorder; DAW sync (host play head/tempo to every plugin); chain latency reported and re-reported on change; plugins + their state + mappings saved in the session (missing plugins named); 8 CV knobs learnable onto any hosted control (Matrix / MIDI / automation drive third-party plugins); sidechain over Rack Link (any track sends A-D, The Bridge feeds hosted sidechain inputs, timeline-aligned). Tested by hosting The Stage VST3
- ☐ The Bridge: CLAP plugin hosting (JUCE has no CLAP host yet - needs a CLAP host layer)
- ✅ The Matrix: session-wide modulation - 4 LFOs (sine/tri/saw up/down/square/S&H/smooth random; free Hz or locked to the host's bars), ENV 1 (Matrix track level), ENV 2 (Rack Link key), 4 macros, random; up to 32 routes to any control on any Solution track with depth ±100% and per-route phase (poly LFOs); routes saved by track name; live source meters; Ctrl+Alt+X. Every module reads its controls through the modulation layer (no cost when unrouted)
- ✅ Surround / Dolby Atmos bed output: every module runs on 5.1, 7.1, 5.1.2, 5.1.4, 7.1.2, 7.1.4, 9.1.6 or ambisonic tracks (input mono, stereo or the same layout); the stereo module output is placed at the 3D stage position (azimuth, elevation, width, motion paths) with energy-preserving 3D panning and a pan law, optional LFE send (80 Hz); bed inputs fold down; speaker map in the stage; object positions also export as ADM (AI Analyze > Metadata)
- ☐ Atmos object tracks (DAW object panner) and Dolby Atmos Renderer: handled by the DAW - the plugins sit on bed tracks; verify in LUNA / Pro Tools / Logic / Nuendo
