MEASURED WITH
How to measure: put this module on a track whose input is your mic (any mic) and whose output goes to your speakers. Any mic works - pick it above (or "Any / unknown") so the plugin can allow for its sound and only correct where it can be trusted. You can change it after measuring; no need to re-measure. Place the mic where your head is, set a comfortable volume, then press ● SWEEP and stay quiet. Correction mostly cuts room boom and never boosts more than 3 dB.
